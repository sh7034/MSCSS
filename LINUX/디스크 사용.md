## DISK 사용 절차
##### Linux
Partitioning -> File system -> Mount
##### Windows
Partitioning -> File system -> 드라이브명 할당
### Partition
물리적 디스크를 논리적 단위로 분할
디스크를 사용하기 위해서는 반드시 1개 이상의 논리적 파티션이 필요
##### MBR
주 파티션을 4개까지만 생성 가능
주파티션중 오로지 1개의 파티션을 확장파티션으로 생성 후 논리 파티션을 12개까지 생성 가능
##### UEFI
128개 주파티션 생성 가능

### File System
파일 및 디렉토리를 효과적으로 관리하는 시스템
##### Windows
FAT16, FAT32, NTFS
##### Linux
EXT2, EXT3, EXT4, XFS
###### EXT3, EXT4
Journaling file system: 파일이나 디렉터리 생성/삭제 시 로그 기록
로그를 통해 파일 복구 가능. 단, 속도가 느려짐
EXT3

###### Linux 시스템 설치 필수 파일시스템
- /
 - boot: 리눅스 커널(Kernel)과 부트로더(GRUB 등) 등 **시스템 부팅에 필수적인 파일**들. 반드시 물리적인 파일시스템에 존재해야 함
 - etc: 시스템의 **모든 환경 설정 파일**
 - home: 일반 사용자들의 개인 저장 공간(홈 디렉터리)
 - root: 시스템 최고 관리자(root) 전용의 홈 디렉터리
 - bin: 시스템을 운영하는 데 필요한 **가장 기본적인 필수 명령어**들 (`ls`, `cp`, `mv`, `pwd` 등). 부팅 전이나 긴급 복구 상황에서도 사용할 수 있어야 하는 명령어들
 - sbin: 시스템 관리자(root)가 사용하는 **시스템 관리 및 복구용 명령어**들 (`fdisk`, `ifconfig`, `reboot` 등).
 - usr: **(Unix System Resources)** 사용자가 직접 실행하는 프로그램과 데이터들이 설치되는 가장 큰 디렉터리. 
 - lib, lib64: `/bin`과 `/sbin`에 있는 프로그램들이 실행되는 데 필요한 **공유 라이브러리 파일**(`*.so`)들. 윈도우의 `*.dll` 파일과 같은 역할
 - dev: 마우스, 키보드, 하드디스크, 모니터 등의 **장치(Device) 파일**들
 - tmp: 시스템이나 프로그램들이 실행 중에 임시로 생성하는 파일들
 - var: 시스템 운영 중에 내용이 수시로 변하는 파일들. 대표적으로 시스템 오류나 접속 기록이 남는 **로그(Log) 파일**(`/var/log`), 메일, 데이터베이스 데이터 등
 - mnt: USB, 외장 하드, CD-ROM, 혹은 네트워크로 연결된 다른 서버의 저장 공간 등을 **시스템에 임시로 연결(마운트)할 때 사용하는 빈 디렉터리**
 - opt: 프로그램과 데이터들이 설치되는 디렉터리. 윈도우의 `C:\Program Files`와 유사한 역할
 - run
- swap

#### Mount
```sh
lsblk -f
blkid
# Partitioning
fdisk /dev/sdb
n
p
w
# Make File System
mkfs.ext4 /dev/sdb1
# Mounting
mount /dev/sdb1 /mnt
# Unmounting
umount /mnt
# File Sytem signature removal
wipefs -a -f /dev/sdb1
# Partition removal
fdisk /dev/sdb
d
w
```

#### Logical Volume Manager
##### 순서
파티션(LVM) -> PV 생성 -> VG 생성 -> LV 생성 -> 파일시스템 -> 마운트
###### Physical Volume 생성
```sh
pvcreate /dev/sdb1
pvremove /dev/sdb1
pvscan
pvs
pvdisplay
```
###### Volume Group 생성
```sh
vgcreate [그룹명] [pv명1] [pv명2]...
vgremove [그룹명]
vgextend [그룹명] [pv명10]
vgreduce [그룹명] [pv명]
vgscan
vgs
vgdisplay
```

###### Logical Volume 생성
```sh
lvcreate -L [용량] -n [lv명] [vg명]
lvcreate -l [PE개수] -n [lv명] [vg명]
lvremove /dev/vg명/lv명
lvextend +3G /dev/vg명/lv명 # 기존 용량에 3G 추가
lvextend 10G /dev/vg명/lv명 # 최종 용량을 10G 로 설정
lvreduce -3G /dev/vg명/lv명

lvscan
lvs
lvdisplay
```

```sh
# 이미 마운트된 LV들이라면 실제 사이즈 증가 명령이 필요
resize2fs /dev/vg명/lv명
xfs_growfs
```
