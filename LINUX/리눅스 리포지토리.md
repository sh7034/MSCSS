### Repository
리눅스 개발사에서 운영하는 인터넷 상 저장소
package들이 주로 이곳에 업로드됨
dnf, apt, zypper, yum

### Package 설치
- Source(Binary) 설치: 커스터마이징 가능(의존성 해결 필요)
- 환경설정: ./configure
- rpm 설치: rpm파일 다운로드 후 설치
- yum, dnf 설치: repository에서 rpm 파일 다운로드후 설치, 의존성 문제 자동해결, 인터넷연결 필요, 최신버전이 아닐 수 있고 커스터마이징 불가
```
./configure --prefix=[PREFIX]
     $ make
     $ make install
     $ PREFIX/bin/apachectl start

```

```sh
# apache2 소스 설치

# 다운로드, 압축, 컴파일, 파싱 도구 설치
dnf install -y wget tar bzip2 gcc gcc-c++ expat-devel

# 필요한 파일 다운로드 및
wget https://downloads.apache.org/httpd/httpd-2.4.68.tar.gz
wget https://downloads.apache.org/apr/apr-1.7.6.tar.gz
wget https://downloads.apache.org/apr/apr-util-1.6.3.tar.gz
wget https://sourceforge.net/projects/pcre/files/pcre/8.45/pcre-8.45.tar.bz2
tar xvzf apr-1.7.6.tar.gz
tar xvzf apr-util-1.6.3.tar.gz 
tar xvzf httpd-2.4.68.tar.gz 
tar xvjf pcre-8.45.tar.bz

cd apr-1.7.6
./configure --prefix=/web/apr
make
make install

cd ../apr-util-1.6.3
./configure --prefix=/web/aprutil --with-apr=/web/apr
make && make install

cd ../pcre-8.45
./configure --prefix=web/pcre
make && make install

cd ../httpd-2.4.68
./configure --prefix=/usr/local/apache2 --with-apr=/web/apr --with-apr-util=/web/aprutil --with-pcre=/web/pcre/bin/pcre-config 
make && make install

vi ~/.bashrc
# PATH 경로 /usr/local/apache2/bin 추가하기

vi /usr/local/apache2/htdocs/index.html


```
